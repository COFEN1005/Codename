# SIGNAL WORDS

4人（2対2）で遊べる、リアルタイム連想ワードゲームです。ルーム作成者は自作のカード候補ファイルを読み込めます。

## ローカル起動

```bash
npm install
npm start
```

`http://localhost:3000` を開きます。テストは `npm test` で実行できます。

## GitHubからRenderへ公開

1. このフォルダをGitHubの新しいリポジトリへpushします。
2. Renderで **New > Blueprint** を選び、リポジトリを接続します。
3. `render.yaml` が自動認識されたら **Deploy Blueprint** を押します。
4. 発行されたURLを4人に共有します。

RenderのWebSocket対応を利用するため、追加設定は不要です。無料プランではしばらくアクセスがないと休止し、最初の起動に時間がかかる場合があります。

## ゲーム仕様

- レッドとブルー、それぞれ「マスター」1人と「エージェント」1人
- マスターだけが未公開カードの色を確認可能
- ヒントは1語と1〜9の数字
- エージェントは指定枚数+1回まで選択可能
- 自チームのカードをすべて見つけると勝利
- 暗殺者を選ぶと即敗北
- 作成者は開始前にカード候補ファイルを読み込み可能（25〜300語）
- ルーム作成者専用の管理者モード
- 管理者モードから接続を手動延長
- 10分以上延長されていない場合だけ画面内ポップアップで通知
- ヒントごとに開いたカードと陣営を記録するゲームログ
- ロビー・ゲーム中のループBGMと、操作・ヒント・カード結果・ターン交代のSE
- BGMとSEを個別にミュート可能
- 回答カードを共有マークしてから開く二段階確認
- ルーム作成者専用のゲーム終了操作
- カード公開時の3Dフリップと、自チーム正解時の成功エフェクト

## サウンド割り当て

- `lobby.mp3`: ロビーBGM
- `battle.mp3`: ゲーム中BGM
- `selectSE.mp3`: ボタン操作
- `hint.mp3`: ヒント表示
- `turn.mp3`: ゲーム開始・ターン交代
- `teamcardSE.mp3`: 自チームカード
- `enemycardSE.mp3`: 相手チームカード
- `neutralcard.mp3`: 中立カード
- `badcard.mp3`: 暗殺者カード

## カード候補ファイル

推奨形式はUTF-8のTXTです。`public/card-sample.txt` をコピーして、1行に1語ずつ書き換えてください。空行と `#` で始まる行は無視されます。

CSVは各行の先頭列、JSONは文字列の配列（`["灯台", "銀河", ...]`）または `{ "words": [...] }` を読み込みます。ルーム作成後に「カード候補ファイルを読み込む」から選択してください。ファイル自体はサーバーへ保存されず、単語だけがそのルームのゲーム中に利用されます。

## 運用上の注意

ルーム情報はサーバーのメモリに保存されます。デプロイやRender側の再起動で進行中のルームは消えます。長期保存が必要になったらRedisなどを追加してください。

Render無料インスタンスの接続延長は、ルーム作成者が管理者モードのボタンを押したときだけSocket.IO経由で実行します。自動延長やブラウザ通知は行いません。管理者モード開始時または前回の延長から10分経過すると、画面内ポップアップで確認します。

このプロジェクトは既存ゲームの公式版ではなく、固有の画像・ロゴ・カードデータを使用しない独立した実装です。
